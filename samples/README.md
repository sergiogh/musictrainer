# Sample Sources

This app bundles a small local subset of the FluidR3 General MIDI samples from:

https://gleitz.github.io/midi-js-soundfonts/FluidR3_GM/

Source repository:

https://github.com/gleitz/midi-js-soundfonts

The upstream README states that the Fluid soundfont was generated from `FluidR3_GM.sf2` and released under the Creative Commons Attribution 3.0 license.

Bundled instruments:

- `clean`: `electric_guitar_clean-mp3`
- `acoustic`: `acoustic_guitar_nylon-mp3`
- `piano`: `acoustic_grand_piano-mp3`

Only these note samples are currently bundled for each instrument: `C2`, `Eb2`, `Gb2`, `A2`, `C3`, `Eb3`, `Gb3`, `A3`, `C4`, `Eb4`, `Gb4`, `A4`, `C5`, `Eb5`, `Gb5`, and `A5`.
